# Architecture Decision Records

Las tareas con etiqueta `Decision` crean ADRs propuestas en este directorio.

Estados permitidos:

- `Proposed`: redactada por un agente y pendiente de revisión.
- `Accepted`: aprobada por responsables humanos identificados.
- `Rejected`: no adoptada, con razón.
- `Superseded`: reemplazada por otra ADR enlazada.

Un agente no puede cambiar por sí solo una ADR a `Accepted`.
